# Nimbus: product overview

Nimbus is a cloud file sync and backup service for small teams. Every Nimbus
workspace includes versioned storage, shared folders, and a desktop client for
macOS, Windows, and Linux. Accounts are identified by a workspace ID in the form
`NB-` followed by six digits, which support agents use to look up a customer.
The service status page at status.nimbus.example is the first place to check
when a customer reports sync failures.
